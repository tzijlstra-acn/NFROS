## Pre-release requirements

- [ ] Full Accenture logo on cover slide (approved asset, not fabricated)
- [ ] Greater Than symbol on subsequent slides (approved asset)
- [ ] Font: Graphik (licensed) or Arial (fallback)
- [ ] No unlicensed font embedded or distributed
- [ ] Sentence case headings throughout
- [ ] Light mode presentation (no dark slides)
- [ ] Core purple as principal accent (#A100FF)
- [ ] No aqua in light deck
- [ ] No circular image crops
- [ ] No rounded-card-dominant layout
- [ ] No mixed light/dark slides
- [ ] No Reinvented with Accenture campaign lock-up
- [ ] No custom NFROS logo or combined lock-up
- [ ] Greater Than symbol not used as arrow or navigation element
- [ ] Co-branding disabled (no client logo unless written permission obtained)
- [ ] Photography is approved, authentic, and diverse
- [ ] No AI-generated photorealistic people
- [ ] Voice: Bold, Optimistic, Agile, Human, Ingenious
- [ ] Weekend language throughout core deck
- [ ] No named competitor attacked
- [ ] All claims supported, illustrative, or proposed
- [ ] AI-assisted content reviewed by a human
